# tag-cli

Bun CLI that tags directories, stored in SQLite. The CLI is generated by
`createCli()` in `src/cli.ts` from `rootRouter` in `src/router/index.ts`: each
tRPC procedure becomes a command, its Zod input becomes the flags and
positionals, and its `.meta()` supplies the help text. Procedures receive `Context` with
`ctx.db` (Drizzle) and `ctx.helpers` (`createDrizzleDbHelpers()`).

## Gotchas
- Two database layers coexist. The app uses Drizzle via `src/db/db.ts`.
  `tests/database.test.ts` still exercises the raw `bun:sqlite` helpers in
  `src/db/index.ts` (`createDbHelpers()`), so a passing test proves nothing
  about the Drizzle helpers.
- Two path modules coexist, `src/util/path.ts` and `src/utils/path.ts`. Their
  `canonical()` is identical, but `getStatePath()` is not. The app database is
  `src/util/path.ts`'s: `$XDG_STATE_HOME/tag/data.db`. `drizzle.config.ts` and
  the legacy layer use the other module and point at different files.
- Directories are stored as canonical absolute paths. Every path input goes
  through `canonical()` before it touches the database.
